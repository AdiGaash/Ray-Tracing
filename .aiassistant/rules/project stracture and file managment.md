## Project Structure & File Management

- **Unity Folders:** Follow this strict hierarchy:
    - `Assets/_Scripts/` (User scripts)
    - `Assets/Shaders/` (Custom HLSL/ShaderLab)
    - `Assets/Prefabs/`
    - `Assets/Docs/` (Generated Markdown documentation)
- **Namespaces:** Do not use any namespace
